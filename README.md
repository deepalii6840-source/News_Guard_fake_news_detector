# News_Guard_fake_news_detector
AI-powered fake news detection system using NLP, machine learning, React, Flask, and Supabase.

NEWS GUARD is a machine learning-based web application that detects whether a news article is Fake or Real. It analyzes the text of a news article and provides a prediction along with a confidence score.

1) Features
   
Fake and real news classification
Machine learning-based prediction
Confidence score for predictions
Simple and user-friendly interface
Prediction history and analytics
Text preprocessing using TF-IDF
Tech Stack

2)Frontend

React.js
TypeScript
Tailwind CSS
Shadcn UI

3)Backend

Python
Flask
Scikit-learn
Pandas
Joblib

4)Machine Learning

TF-IDF Vectorization
Passive Aggressive Classifier

5)Dataset

The model was trained using a combination of fake and real news datasets. The data was cleaned, preprocessed, and converted into numerical features using TF-IDF vectorization.

6)Model Performance

The trained model achieved approximately 88.52% accuracy on the evaluation data.

7)Disclaimer

NEWS GUARD is an academic/project-based application intended for educational purposes. Predictions should not be considered a definitive verification of news authenticity.
